# Оформление Markdown и AsciiDoc

## Структура текста

Разделяй самостоятельные темы на разделы и подразделы с содержательными заголовками.
Внутри темы оформляй перечисления списками из коротких пунктов; длинные пункты разбивай на подпункты.
Используй смысловые переносы строк (Semantic Line Breaks): каждое предложение начинай с новой строки, связанные предложения объединяй в абзацы, абзацы разделяй пустой строкой.
